# Lessons from local fixed corrections (synthetic)

When a per-batch constant improves a selected row but worsens another row in the same batch, the selected improvement does not establish a batch-level correction. Here the two second rows retained error 3 after the local edits. This only rules out the present fixed offsets on the supplied examples; it does not establish whether a contemporaneous reference can support a better producer or whether the mechanism transfers to other data. Compare the actual all-row and per-batch outputs before claiming a result.
