# Reference and baseline preflight

A stationary reference sensor has known value 5.0. Calibration (`data/calibration.json`) reports reference reading 6.5 during the drifted batch, so its independently observed offset is +1.5. For the two calibration target rows, the uncorrected baseline errors are +1.5 and +1.5, hence baseline MAE 1.5; subtracting the calibration offset leaves zero error on those two rows. This is a small rationale for a directional prediction, not a guarantee about holdout rows.

For the held-out comparison, use *the same rows and scoring*: baseline = raw target reading; initial candidate = raw target reading minus the calibration offset; metric = mean absolute error against target truth (scoring only). The holdout reference reading is a separate predictor available at inference time; if the calibration-batch assumption fails, compare a local reference-based correction against the original baseline without deleting the initial result. Holdout truth is for scoring only. Keep supplied data unchanged. Any error reduction would support only this fixture's bounded correction claim, not general performance or a physical mechanism outside the supplied data.
