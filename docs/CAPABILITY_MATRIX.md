# Capability matrix

Dove is one research partner. Ordinary Claude conversation is the primary entrance; the optional agent and seven flat Skills add no personas, stages or permissions. The main session owns conversation, execution and adoption. Bounded requests keep their scope.

## Seven Skills

| Skill | What it helps with |
|---|---|
| `dove.research` | Build body-grounded gaps and cross-field candidates and offer the user a choice; then advance the confirmed mainline through the six moments of the operating manual. |
| `dove.status` | Read the card, the main metric and trend, recent method versions and the brief; report results, blockers, this round's aim and due date without new work. |
| `dove.source` | Discover sources, verify citations and claims, and accumulate question-led full-text notes in `papers/<id>.md`. |
| `dove.experiment` | Form methods from real failures and test them through fair comparisons at a scale that can tell the result. |
| `dove.draft` | Write and revise the authoritative manuscript, group related work from the paper library, export verified BibTeX, and respond to reviews with evidence-backed revisions. |
| `dove.figure` | Gather materials, draw, inspect and deliver figures, captions and editable sources. |
| `dove.review` | Distinguish author self-check, delivery inspection, independent current-paper review and returned opinions. |

## Surfaces

| Surface | What it provides |
|---|---|
| Project rule (operating manual) | The one place operating rules live: three records, six moments, what belongs to the user, when to stop, reporting |
| User's most frequent sayings | Twelve verbatim quotes with dates and what to do; read at the start of every main context |
| Research standard | Researcher stance, from problem to method, eight dimensions, evidence, topic and novelty; read by the mentor and reviewer and at named moments |
| SessionStart / UserPromptSubmit | Identity card and this round's situation; one notice after an update |
| Stop | One quote of the user's words on an overrun and one on a stall; can be turned off |
| Status line | Three lines: session facts and mainline; main metric, this round's aim and due date; project path |
| `dove-mentor` / `dove-review` | Fresh read-only contexts |
| Paper-search / Exa MCP | Declarations, not access approval |
| Dashboard | Progress, trend, verdicts, overrun and stall, a per-round ledger and bias table, pending decisions, cross-project lessons, recurring corrections and corrections per round |

Installation does not prove reading or behavior; see [Usage](USAGE.md).

## Completion and evidence

Requested-work completion, scientific progress and [software verification](PACKAGING.md#verification-evidence) differ. Negative evidence can settle a method decision without completing the goal; plans and engineering checks are not scientific results. Submission needs scientific sufficiency, independent review of the same complete current version and actual delivery readiness.
