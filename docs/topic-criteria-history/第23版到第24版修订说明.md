# 第23版到第24版修订说明

日期：2026-10-08。

## 一、为什么修订

用户在讨论第 18 轮候选 OCS 时问：这种新颖性写出来能达到什么论文水平，并提出“以一些论文榜单去衡定我们的评价”，随后明确“先按会议去定我们的选题要求”“先按 a 会要求去定第一档”。第22、23版用抽象条款和“录用／被拒”二分来校准门槛，无法回答“能上哪一档”。

## 二、依据

- CCF 第七版推荐目录（2026-03-31 发布、4 月勘误）：ICLR 新进 A 类，IJCAI 由 A 降 B，TMM 由 B 升 A；Findings、Workshop、短文不计入。
- 第一档各会官方审稿指南与录用统计：CVPR 2026 约 25.4%、NeurIPS 2025 24.5%、ICLR 2026 约 27.4% 等（ICCV、ACM MM、ACL、AAAI 录用数未核实）。
- 本方向（视频空间推理、三维空间问答数据、幻觉、数据或标签配方、发现＋修法）在 CVPR、ICCV、NeurIPS、ICLR、ICML、AAAI、ACM MM 上的已核实录用锚点论文，以及 ICLR 2026 同类被拒或撤稿样本（VST、GRAID、SpaceR、SpaceVista、ACFT）及其评审理由。
- 调研全部为文献与官方页面阅读，未做实验。

## 三、改动

| 条款 | 改动 |
|---|---|
| 开头 | 版本说明；“够不够格”的参照明确为目标会议审稿人 |
| §0.1 | 新增第 0 步：定目标会议与档位 |
| §0.2 | 新增一条硬规则：先声明目标会议，以第一档（CCF-A）标尺判断，强结果也到不了 CCF-A“中”档的不进入定题或有条件开题，降档须用户同意 |
| §2.0（新增） | 档位表（CCF 第七版）；目标会议规则；预期档位写法（温和与强结果两种情形）；第一档标尺（新颖性、证据包、增益量级、算力） |
| §2.4 | 创新性“满足”以目标会议第一档标尺判断 |
| §2.5 | 证据包改为第一档要求：2 个底座家族、3–4 个以上基准（含分布外与通用能力）、受控对照、噪声抽检、数据公开 |
| §2.6 | 增加“预期增益是否达到目标会议量级” |
| §2.9 | 新增第 6 条：已声明目标会议，强结果至少在一个 CCF-A 会议达到“中”；判读规则写明第一档与 B 档两档阈值 |
| §13.9 | 审稿模拟先写目标会议与预期档位 |
| 附录 A、B | 候选卡与开题检查加入目标会议与预期档位 |
| 附录 E | 记录用户 2026-10-08 的两句要求 |
| 附录 F（新增） | 会议画像、锚点论文、被拒样本、B 档以下参考、定档清单 |

## 四、没有改变的部分

第23版关于新颖性判法（第一档只认本领域一对一映射等）、有条件开题、审稿模拟与成对排序、门槛校准、找题期间不做实验（附录 E）的规则全部保留。

## 五、对现有候选的影响

- OCS（按模型实际看到的帧重算视频空间训练标签）：与最近工作（Stream3D-VLM、S3-Train、SpatialMosaic、Ouroboros-Spatial）距离为“改编级”。按附录 F：温和结果（主指标 +2）过不了第一档，A 类中只有 ACM MM 为“中”；强结果（针对性子集明显提升、2 个底座、完整分析）在 CVPR、ICCV、NeurIPS、ICLR、ICML 约为“中”（接近一半一半），AAAI、ACM MM 为“中-高”。按 §2.9 第 6 条，OCS 在强结果情形下满足最低要求，但需按第一档证据包补强：两个训练来源上复现三组对照、按可见比例分桶的剂量—反应曲线、公开重算标签。
- 其他第 18 轮候选（坐标读出、子空间计数、几何事实写回）在第23版下已排序靠后，第24版不改变其处置。
