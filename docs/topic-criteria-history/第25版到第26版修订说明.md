# 第25版到第26版修订说明

日期：2026年10月9日。用户在对照两份反思、审阅具体修改建议后明确要求“修改”。本次重写文档，不找新题，不运行模型或实验。

## 1. 文件与效力

- **现行文件：**根目录 `论文选题准入标准_最新版(26).md`。
- **历史原件：**本目录 `论文选题准入标准_最新版(25).md`，内容原样保留；原有 `论文选题准入标准_最新版(25)_补充前.md` 未改。
- 第26版是完整替代稿，不是在第25版前后追加补丁。旧章节编号、模板、历史“全部保留”说明不与现行正文叠加执行。
- 本说明只解释修改，不独立设置准入条件。知识库入口同步指向第26版；旧候选、协议、实验结果及校准记录仍保留历史口径。

## 2. 为什么重写

第25版已写有允许正常经验未知、算子等价不等于贡献等价、保留任务脉络和限制互审轮数等正确原则，但另一些硬门槛及重复模板会将它们重新收紧：六项全满足、主观录用“中／高”、必备四类可解性证据、自然做法须已失败、统一证据包、开题报告强制实验协议等。

本次将判断对象统一为：**当前研究依据是否足够，而不是未来论文结果是否已经成立。**同时保留实质方法差分、核心合同、标签与部署合法性、查重和资源可行性，不改成“有想法、试验便宜就能开题”。

## 4. 没有改变的边界

- A会目标与方法贡献偏好；不自动降档，不改成benchmark或诊断项目。
- 当前VLM/VQA范围、OCR／文档转录和数值优化主线偏好、公开资源约束。
- 默认选题期不实验，例外须用户同意；开放式观察只是可能另行授权的方式，不是新增默认权限或强制流程。
- 通常单项目一张当时空闲GPU，服务器整体空闲时可适当放开；未新增统一时长预算，也不要求已有授权内每个操作再次审批。
- 真实查重、核心方法定义、标签语义、部署信息、源身份划分、测试集隔离及诚实报告。
- 不事后修改判读、指标、基线或检查点规则救题；设计变更遇到授权缺口先停下说明。
- 用户对旧题的撤回、停止、封存和明确禁向。本版没有重新审理旧候选，也不自动恢复OCS或其他尝试。
