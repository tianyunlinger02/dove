## 一、第21版第6.4节：对近期 VLM/VQA 方向卡的回溯处理（原文）


以下仅说明第19版会怎样处理此前方向，不是重新裁定论文新颖性：

| 方向 | 风险叠加 | 第19版定位 |
|---|---|---|
| 冲突/未知四值证据状态 | 新状态、新来源标签、新决策合同、真实数据来源不足 | 探索型；不能与成熟任务小改动同层比较后直接主选 |
| 最小视觉证据超图 | 新证据对象、新逻辑标注、新图结构、新忠实性评价 | 探索型；先拆分主创新或降低数据/评价风险 |
| 变换等变答案代数 | 数据和任务较成熟，但直接组合与数据增强覆盖风险高 | 平衡型边缘；应先证明不是系统化增强包装 |
| 跨层证据干预签名 | 因果状态、干预数据、双前向成本和路由近邻同时存在 | 探索型；不默认作为当前主选 |

这说明前一轮候选池风险结构单一，不能据此让用户选择一个“相对最好”的高风险题。

本节按第20版保留为历史回溯，不代表本轮重新核验相关论文或重判旧题。表中“证明不是系统化增强包装”应执行为具体技术差分审查，不是把数据增强或一致性训练作为否决类别。标准修订不自动恢复或判死任何旧候选。

## 二、第21版正文末尾的旧版修订记录（原文）

## 修订记录：第19版到第20版

第19版解决了候选风险过度集中、为了躲避组合覆盖而不断把题目推向高风险前沿的问题。第20版进一步解决另一项反复出现的失误：候选往往先因为“问题真实、方法能做、数据可用”被推荐，直到后续深查才发现**贡献句不清或创新性并未真正成立**。

本次新增：

- “问题、方法、贡献、创新性、可行性、重要性”六点强制结论制度；
- 六点之间不可相互替代的明确规则；
- 贡献与创新性的强制拆分：先说明论文新增什么，再证明为什么不是已有工作/组合；
- 每个方向卡、方法文件、主选候选和正式开题都必须给出六点表；
- 必须单独给出“六项是否同时满足：是/否”；
- 任一关键项未满足或待决定性核查时，正式定题结论必须为“否”；
- 正式主选默认只允许“六项同时满足：是”的候选；
- 六点结论与六维风险预算并行使用：前者判断题目是否成立，后者判断成立后的风险程度；
- 附录模板、四阶段交付、成熟度与发布前检查全部同步更新。

第20版的默认决策顺序因此变为：

> **先问六点是否都成立，再问风险是否可控，最后才决定是否正式推荐。**

这避免再出现“方法写得很完整、可行性也不错，但创新性直到最后才发现站不住”的候选被过早包装成主选。

## 修订记录：第20版到第21版（原件核对）

本版直接从重新上传的第20版原件修订，保留其十三章框架与原附录 A、B；新增内容来自用户已确认的经验，不把先前缺少原件时重整的第21版当作权威底稿。

| 原件中的条款与经验 | 本版处理 |
|---|---|
| 六点、成熟锚点、六类风险、四阶段、N/T和选题不运行实验 | 保留，并同步解释与模板。 |
| 组合可以创新、不要求新基础原子、不机械要求固定候选数、改判应有依据 | 原件已有；加强执行边界，不冒称第21版首次加入。 |
| 自然生成多处被写成必须有最小新对象或结构性矛盾 | 有意修订：可从具体技术取舍提出新监督、训练或计算关系；不要求唯一解。 |
| 贡献与创新性有区分，但容易互相重复 | 明确预期知识／能力主张与相对先例比较；不能预写已取得结果。 |
| 六点的“满足”可能被当成实验已成功；未知与反证混用 | 定义为开题依据，增加“待核实”，保留整体是／否和正式推荐门槛。 |
| 宽泛调查后不断换任务 | 新增方法脉络、四段式技术论证、同问题解法比较和返回位置。 |
| 组合闭包有要求，但容易仅列组件就否定 | 区分运算等价、接口仍缺和表达能力覆盖；正反判断均需具体构造。 |
| 风险预算和成熟锚点有明确默认配置 | 保留原默认和详细表；明确风险额度不能豁免六点决定性缺口。 |
| 第十二章三类研究路线在此前重整稿中未单列保留 | 恢复原章和路线差异，仅同步路线A不强制新状态。 |
| 用户质疑后容易无依据改判 | 扩展维持、限定、暂缓、撤回及异议记录，区分兴趣与学术判断。 |
