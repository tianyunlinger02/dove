# 选题标准的修订历史

Dove 的选题标准由 Dove 维护：现行正本是 [`docs/TOPIC_CRITERIA.md`](../TOPIC_CRITERIA.md)，安装到各项目的 `.dove/install/TOPIC_CRITERIA.md`。它最早在 point1 项目里迭代，此后由 Dove 根据各项目的实验结果修订，项目不再各自更新。

本目录保存第 16、21–26 版原文、各版之间的修订说明和门槛校准记录，只供溯源，不与现行版本叠加执行。第 27 版只修了一处缺陷：选题的出口是用户选定主线，方法在主线中形成（见“第26版到第27版修订说明”）。

第 29 版到第 30 版（2026-10-28）：用户多次指出选题和推进“老是反向排除而不是正向思考”（10-26：“记得是正向寻找，从已有的最新研究出发，而不是先随便虚构一个方案，然后不断收窄方案直到达成我的约束”；10-27：要的是正向证据，不是反向例子说不能）。第 30 版在 2.1 加入正向寻找：从近两年最强工作已经做成的和明确留下、有迹象能补的缺口出发，组合出一开始就满足约束的方案，每个候选写明正向依据；3.3 加入推荐、继续和开轮看正向依据，“没有反证”只说明不必放弃；5.1 要求一轮至少交出一个有正向依据的方案。第 29 版原文见同目录。
