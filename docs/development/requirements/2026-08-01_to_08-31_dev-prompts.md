# Dove 早期要求清单（2026-08 用户提示历史）

材料：用户在服务器 Dove 开发目录里亲手输入给 Claude Code 的提示，2026-08-01 至 08-31，共 429 条（08-01～08-19 一个会话，08-20～08-31 另一个会话）。这里只整理用户提了什么要求，不判断现在的 Dove 有没有做到。

读法：
- 每行格式：`[日期] 类型 · 要求（白话） · 用户原话 · 来源`。类型分六种：总目标、科研做法、对Dove的批评、具体修改指令、约束与偏好、发版与流程。
- 同一要求说过多次的合成一行，方括号里列出每次的日期；同一天里重发或接着说的只记一次日期。
- “来源：本人”是用户自己打的字（包括他直接打进消息里的助手方案或外部文章片段）；“来源：贴入材料”是用户贴进来、夹在贴入块里的长段内容，多半是助手给的方案，用户拿来当指令用。
- 后面的话改动或推翻前面的要求时，行尾注明“修改了／推翻了 [日期] ……”。
- “右边／右侧”指用户看得见的 tmux 测试窗格，里面是一个装了 Dove 的真实科研项目，用来实测 Dove。
