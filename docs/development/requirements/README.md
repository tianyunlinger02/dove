输入历史只有用户打的字，没有助手的回复；当时贴进来的长段内容有一部分已经找不回，清单里注明了。

怎么用：

- 删改一项功能或说法前，先查它对应哪条原话。只说过一次的要求同样算数。
- 用户后来改了主意的，以后来的为准；清单里写了“修改了／推翻了”。
- 贴入材料和别的会话转达的话单独标了来源，不等同于用户本人的话。
- 用户新说的要求，按同样格式（日期 · 类型 · 要求 · 原话 · 来源）追加到对应时间段的文件末尾，或新开一个文件。
