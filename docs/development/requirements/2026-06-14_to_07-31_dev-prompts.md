# Dove 早期要求清单（2026-06-14 至 07-31）

材料：服务器上 Dove 开发目录（/home/nvme01/paper_factory）里，用户亲手输入给 Claude Code 的提示历史 history-2026-06.md、history-2026-07.md，共 391 条消息（6 月 166 条，材料实际从 06-14 开始；7 月 225 条），分属 3 个会话。助手回复没有保存，下面只依据用户的话和用户贴入的材料整理，不判断现在的 Dove 有没有做到。

读法：
- 每行格式：[日期] 类型 · 要求（白话一句） · 用户原话 · 来源。同一要求说过多次合成一行，方括号里列出每次的日期。
- 类型六选一：总目标、科研做法、对Dove的批评、具体修改指令、约束与偏好、发版与流程。
- 来源：「本人」指用户自己输入的话；「贴入材料」指材料里夹在贴入标记之间的长段内容（多为助手或他人的分析，用户贴进来通常是要求照此处理或作佐证）。少数消息里用户把助手的话直接粘在正文里、没有贴入标记，按「本人」计。
- 原话逐字照抄，每段不超过 50 字；一行引了几段时用「／」隔开。
- 行尾的「修改了／推翻了 [日期] ……」表示这条改动了更早的要求。
- 密码、密钥、IP 地址和端口一律略去。
- 文末有「只说过一次但分量重的要求」、行数统计，以及附录（没有单独成行的消息）。
