# Dove 3.4.11：研究者立场与行动取舍

## 这次改变什么

把大局意识、问题品味、整体更优、创新与独立判断、合理胆识、求真、韧性和主动担当融入同一份研究者立场。它不是写作专项指南，也没有新增轮次机制。

- 人读总纲在 [愿景与研究者立场](VISION_AND_PRINCIPLES.md)。
- 运行时唯一来源是 `src/core/dove-research-contract.mjs` 的 `DOVE_RESEARCH_STANCE_BULLETS`；既有共享 renderer、质量摘要及全文复用该来源，普通 Claude、DSH Skills 和导师实际读取的材料都能收到。
- 默认入口先理解当前请求、核心能力与完成含义。已授权的实现、修复、复现和有界交付不被重新变成选题或轮次管理。

## 替换的具体取舍

| 原有要求 | 3.4.11 |
|---|---|
| 最弱维度决定下一轮、候选修改只点一处 | 用维度发现瓶颈、共因与关键未知，比较协调修改、核心重构和替代路线的整体价值。 |
| 连续两轮无科研结果后，第三轮请用户重新决定继续 | 失败计数触发独立停滞诊断，不自动重批；可信且已授权的下一步继续执行，改变承诺或确无可信路径才交用户决定。 |
| 方法代码一改就完整评测 | 开发诊断回答关键未知；正式比较、结果采纳和论文主张完成实际版本的适用协议、用户指标与公平强基线。未重测效果仍未知。 |
| 修评价器先重算全部历史 | 立即标明受影响结果，先恢复当前主张、必要历史比较和强基线；其余保留为明确的旧协议历史，不混用、不隐藏不利证据。 |
| 选题检索数量和跨域数量成为交付要求 | 数量是拓展视野的参考，不是配额；按实质近邻、机制证据、关键未知与反对意见决定行动。 |
| 固定结论词、证据句数、开头禁令及检查逐项自证 | 自然直接回答，给判断所需的证据与关键未知，让检查服务行动。 |

跨域机制生成原则从未被共享入口消费的导出接入默认判断。恢复上下文时，从目标、核心能力和最有价值的已授权行动继续，而不是只读记录。面板候选说明与“修改焦点”标签同步，不再暗示逐项补洞。

没有新增 Skill、人格、hook、必读文件或迁移待办。作者原话全文、用户固定承诺、正式公平评测及独立审稿只读边界保留。
