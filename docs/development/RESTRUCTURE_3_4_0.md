# Dove 3.4.0：一次整体结构调整

本次依据用户已确认的 2026-10-15 方案整体重写，不拆成多次小发版。下面的历史问题来自方案中的真实使用复盘，不是本次新跑的科研观察。

## 改了什么，以及为什么

| 触发问题 | 本次调整 | 正常使用中要看什么 |

## 记录上限

- 身份卡：1200 字符，包含目标档次、限制来源与范围、研究状态。
- 每轮说明 / 结果：分别 2000 / 3000 字符；结果固定写变更与版本、测量与产物、预测与实际、反驳与事实更正。
- EVAL：一方法版本一行，固定七列；每格最多 200 字符。当前八维判断最多 1000 字符，替换旧当前判断而非累计评分日志。
- 导师每次笔记：1000 字符；总长超过 6000 时由导师合并成不超过 3000 字符。执行者不代写。
- 领域扫描：2000 字符，另存日期文件。

这些是今后研究记录的写法。安装不会迁移、缩写或重写已有研究历史。

## 删了什么

删除九项能力之间重复的主线、导师、记录、工程职责说明；删除“推荐一个便实现”的选题路线、默认最小核心的取向、导师工程裁决和评价器修复责任，以及与明确触发矛盾的“需要时才调”。保留来源核实、实质实验、真实图表与图注、权威稿件构建、独立审稿、作者回复和有用经验。

没有新增审批、防护、哈希、冻结门、模型调度框架或研究数据库。没有改作者偏好全文，没有创建测试项目，也不向真实项目写测试内容。
