# Dove 3.4.10：意图对照与追踪闭环

本版只修改 Dove 产品，不替登记科研项目更改方向、补实验或改研究结论。

## 改了什么

- 长期意图由首次导师的工作改为周期职责。调用材料按导师笔记最近一节的有效日期判断：没有带日期的长期意图，或严格超过七个本地日，就提示到期；恰好七天不算。面板和调用材料共用解析，保留子标题、正文和日期，不用普通笔记日期替意图续期。
- 记录中的“用户原话／用户确认”按 `USER_ORIGINALS.md` 核对本人或转述来源。只有转述就标转述；汇总缺项、未整理完或尚不覆盖该宿主，不是否定用户说过或阻断请求的依据。
- 常驻面板在每日调度中为全部登记且仍存在的项目预热原话汇总，独立于论文追踪的开关和当天成功状态。继续使用增量整理及每项目预算，并明确目前仅整理 Claude Code、不含 DSH。
- 项目主线下展示核心能力；导师最近的长期意图及日期默认折叠，展开状态在内容重绘后保留。
- 导师建议由主会话通过 `dove watch configure --project <root> --mentor <建议.json> --json` 明确保存。建议中的字段替换、缺席字段保留，保留项目开关和分类；保存后回读实际配置。`source: mentor` 表示建议落盘，不是用户确认科研方向。这个命令不调用导师或网络。
- Hugging Face 请求对瞬时断连、SSL EOF 和适用的临时 HTTP 错误有限退避，保留失败说明及其他日期已取得的论文；不关闭证书校验，不反复重试永久请求错误。

## 替换和删除

替换了“没有导师笔记才整理长期意图”的职责和仅靠自然语言要求保存追踪配置的旧说明；同步修正直接相关文档中残留的四问及硬篇幅表述。没有新增规则段落、篇幅或措辞门禁，也没有更改累计 `HOST_MIGRATION_TASK`。测试测日期、读取、保存、调度和请求行为，不锁导师规则原句。

## 证据边界

Semantic Scholar 当前生产入口是 JSON POST batch，不是 search/bulk。历史本地证据只能证明 429，不能证明旧 400 的根因；不得把改 POST、改查询语法或 mock 400 当成真实修复。运行证据和发版结果保留在 `runs/artifacts/dove-3.4.10/`。

软件检查、CLI 运行、安装文件更新、面板重启和导师实际采用是不同事实。此次不运行科研导师模型，不因此宣称归因错误已在科研记录中更正或科研方向已经改善。
