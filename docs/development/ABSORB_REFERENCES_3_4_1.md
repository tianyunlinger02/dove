# Dove 3.4.1：把参考项目的长处换进现有流程

依据用户已确认的 2026-10-15 参考吸收与宿主迁移／导师模板两份方案实施，合并 ar-garment 指导钩子修复，一次发布。先读了 IdeaScientist 的 `paper.txt` 附录 A.2 表 3–7、相邻检索说明及 `code/ideascientist/harness/roles.py`，再读 AISafetyHot-Hub 的两份文献 Skill、每日清单和方向索引原文。参考仓库只用于理解做法，没有修改或打包它们。

## 替换了什么

- **选题不再先有方法再补理由。** 用挑战轴和有正文依据的近未成工作找缺口：已有方法通过 Y 做 X，但 Y 留下 Z。每轴至多两个缺口，说明论文各自差在哪里、缺陷类别，以及什么观察能说明缺口被补上。不能用“没人做过”或未读全文作依据。
- **检索不只用来扣新意。** 针对缺口，用 6–10 个查询跨至少三个其它子领域找结构相似的机制；本领域来源仍可用，但不能只是重新发现最近邻。IdeaScientist 的 §5.3 报告领域内新颖性从 36.3% 到 67.0%，这是其研究设置中的模型评判结果，不是 Dove 已获得的提升或录用保证。
- **候选卡不再是六点打勾。** 换成一句话、缺口、来源机制、对应关系、成立前提、近邻差别、最大风险；改进已有候选时说明改了什么。导师主动按机制加目标问题检索反证，给留下、只修最弱一项或否掉，带论文证据和一句最强反对。
- **读文献不再重复从头查。** 需要正文细节时带 1–5 个问题阅读，`papers/<编号>.md` 累积一段内容说明、逐问回答和正文定位；已回答的问题直接复用。新意与撞题判断引用这些笔记。
- **论文列表不再拿关键词命中当内容简介。** 中文一句话置于标题下，原摘要和入选依据折叠在后；一句话尚未有人补充就明说，不伪造自动中文总结。导师或主会话按实际摘要补写；摘要不冒充已读全文。
- **有用论文不再只留在日报。** 已判断为新基线、可借用或撞题的论文按方向累积成项目 JSON／Markdown 文献库，保留作者、日期、会议或 arXiv 编号与链接，支持 BibTeX。写相关工作按方向利用已有材料；未知作者、会议、结果不编造。

仍然是一位 Dove，通过上下文隔离取得独立判断；不是移植五种人格或另建调度系统。方法贡献门槛只在项目标准要求时适用，不把数据、基准、分析等贡献一概排除。没有复制其训练、270 万论文库或以模型分数替代科学判断的机制。

## 删了什么

用具体的缺口、机制、候选和评审内容替换导师笼统的选题节与候选六点格式，删除对应的六点解析和指示灯；读文献与相关工作动作在原 Source／Draft 职责内合并，不在九项能力旁另加新入口。保留 3.4.0 的用户选主线、导师只管方向、规模回答问题、短记录与无结果及时找用户。

没有增加防护、审批、冻结门或哈希机制。安装不创建文献库或问答笔记，也不直接迁移研究记录；开关打开时只登记软件迁移待办，实际整理交给项目宿主。没有修改作者偏好全文，没有创建测试项目，没有改 point1 的 `runs/topic_selection_20261015/` 或其它选题材料，也没有替它继续选题。

## 同批加入宿主迁移和导师模板

`hostMigration` 是默认关闭的用户设置，CLI 和面板都能改。本服务器按用户要求打开；连带更新登记当前版本的一次性待办，两个上下文钩子只读送达。由宿主在当前工作告一段落后整理身份卡和 EVAL，旧长内容原样归档并链接；超长导师笔记和自动初稿追踪配置交下一次导师调用处理。不暂停或重启训练、评测，不重算结果，不改研究结论或用户原话。宿主完成后删除待办；不适用项说明原因，同一版本不再登记。

送达时机还受宿主影响：本机 Claude Code 2.1.199 的空闲任务通知可能走 UserPromptSubmit，运行中的通知可直接作为附件进入上下文，并非每条都触发；SessionStart 只对应启动、恢复、清空和压缩。因此不承诺更新后立刻送达或完成，下一次适用钩子会再次呈现。没有为此新增 Stop、强制唤醒或重启。宿主事实核对首次运行包装器的版本／帮助时产生了本仓库会话临时目录，未创建研究测试项目，也未读消费者研究。

手写“只交材料、不框定”改成 `dove mentor brief` 生成固定调用正文：实际材料路径、近期 EVAL／轮次、用户原话来源与范围、追踪材料，末尾固定四问。执行者只能另附限长署名意见和新原始产物路径，同轮再调用在固定位置注明触发条件；不是新增模型调度或审批入口。

## 正常使用里要观察

point1 正常继续时，观察是否先出现有正文依据的缺口、真正跨领域的机制来源、清楚的对应关系，以及带反证的三种评审结论。不要为验收重跑、改卡或替它补选题材料。

其它项目正常追踪与写作时，观察中文一句话是否忠于摘要，有用论文是否按方向累积、BibTeX 是否沿用真实元数据、已有问答是否减少重复检索。更新后观察宿主是否在合适时机整理已有记录、保留历史且没有打断在跑任务；下一次导师调用是否改用固定模板、正文是否更短且不再被执行者框定。磁盘安装与软件检查不能证明这些行为已经发生，活会话也不会因文件更新自动完整重载。
