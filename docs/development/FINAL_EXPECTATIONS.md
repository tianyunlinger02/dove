# 最终期望

本文描述用户在真实使用 Dove 时应看到的结果。这些是产品验收目标，不表示当前实现已经全部达到。

## 用户面对一个完整 Dove

用户可以直接告诉 Dove 当前研究目标、问题或希望达到的结果。Dove 会理解项目现场，找出最重要的不足，自行选择来源、实验、分析、实现、写作、图、Review、Rebuttal 或 Lessons 等能力并开始工作。用户不需要理解内部实现、文档结构、Skill 清单或角色切换，才能获得高质量研究推进。

当前可见会话已经包含明确科研方向、证据、产物和未完成行动时，用户说“继续”应自然沿该上下文续接。可见上下文不足以确定要继续什么时，Dove 提出最小必要澄清，并说明澄清会改变什么行动。

普通 Claude 主会话通过项目 rule 是首要且完整的入口，负责用户对话、澄清、执行与返回结果采纳。`claude --agent dove` 和九个平级 Skills 只是可选快捷入口，不增加人格、权限或判断权威。UserPromptSubmit 只读核对集成，当前时呈现身份卡与指导，否则非阻塞提示；不分类、不写研究、不代做判断。导师与审稿用独立原生只读上下文，不取代主会话；有界和普通任务保持原范围，没有 Auto、hidden intake、router 或逐工具科学审批。

## Dove 主动形成和检验路线

Dove 理解真实问题、关键不确定性、要改变的决策和完成含义，已有主线不因接手而重选。接口、输入—输出能力、架构、原型、继承实现或成熟代码不自动建立科研价值，但用户明确固定的做法必须尊重；可用数据、benchmark、teacher output、监督、继承输出和便利指标也不因现成就定义目标、reference truth 或成功。Dove 查清未满足的现象、知识缺口或实际需要，不为纯理论工作虚构用户，允许简单方案已足够或扣除覆盖后没有剩余科研贡献的结论，不能据此悄悄降低用户目标。数学、物理或跨域机制可形成直觉、类比和候选解释，再用相关理论、论文与观察检验。

文献会被当作创新燃料来读：共识、矛盾、未验证假设、可迁移机制和未探索 regime 都可能改变路线判断。直觉会被明确当作待验证假设，而不是直接写成结论。对拟声称的新贡献，Dove 在会影响核心设计、范围或投入时先做定向近邻扣除，并把覆盖和仍独立有价值的部分反馈给方法；它不会把穷尽检索变成 informative prototype、确认复现、bounded implementation、修复或交付的先决条件。

Dove 以完整目标的具体任务收益、相对合理替代的价值、机制依据和决定性未知，选择实际核心实现、机制补强或辨别性取证，不默认缺陷→原因→唯一改动→局部数值。导师一页 brief 自然说明收益与依据、关键未知、实际行动及结果如何改变决定；对照、预算、输入边界、预测／阈值和失败材料按用途给出，不套固定字段或编数。主线内未固定方法可调整，不逐项审批；复用有效证据，只补变化、矛盾或决策缺口。核心切片连接机制与真实上下游，落实必要操作、权威 producer—consumer 合同、可见失败与观察，不等完整 baseline 库、全部指标、理论证明、论文论证或已证收益，不停在设计，不加阶段、schema 或 gate。

完整任务与合理外部比较回答效用，内部消融／机制对照回答归因，两者不替代。Dove 检查评价链与依据，按真实代码、配置和输出识别混杂；正式因果对照固定其他因素，不能把整套胜出当成组件增益或机制支持。对照无辨别力时先判路线价值，再比较修复、重设计、替代、辨别性取证与停止，不默认最小补丁、收窄文字或加跑，结论仍受现有证据约束。最低充分证据与有意义收益是充分性下界，不限制改动只能最小。design-only 保持只读，小样本诊断不冒充总体充分性，不强制模板或自动 gate。

每个结果先被吸收到机制、假设、预测、证据范围、主张强度、关键产物或下一行动，再决定是否继续、修正或停止。Dove 会区分原命题获得支持、被反驳、证据不足和当前对照无法识别；组件效应、局部指标增益或诊断观察只支持实际识别的局部命题，只有它实质强化仍值得推进的整体贡献且重要替代解释得到相称控制时才继续深化。negative result 和 near-miss 可以启发新方向，但新方向成功不能覆盖原命题失败，也不能无限补查以推迟接受反证。事实上的否定不等待用户批准，实质改变确认主线或完成含义才请求用户决策。

Dove 能说清“代码、数据和仓库连续，但科学任务已变”：比较真实问题、对象、输入约束、输出、baseline、目标与 proxy、核心命题、贡献及完成含义，包括跨轮小改动的累积影响。保留原命题结论、有效证据和资产；幸存组件或新解释可在已有授权内暂定探索，按拟投入与用途判断价值、新颖性、机制、方法、评价、可行性和资源，不继承旧任务的成功。需改变用户承诺的主线时问用户，不把完整论文论证设为最小探索前提。修正错误指标、分母或采用更忠实 baseline 不机械算换题。

## 用户能观察到判断真正改变行动

- 定向近邻检查确认拟声称的独立新意已被覆盖时，Dove 撤回该贡献并停止依赖它的完整实现、扩量或结论升级；仍可完成不依赖该主张的获准复现、交付或局部工作。
- 核心方法效果未知，但具体假设、关键操作、资源和辨别性观察足以指导最小端到端工作时，Dove 直接推进授权内核心实现，不先要求完整论文题目、贡献论证或评价器，也不要求先调用某个 Skill。
- 核心评价失效、泄漏或无法识别主张时，Dove 不扩大依赖该评价的实验和结论；先修复／替换评价或选择能区分问题的证据，同时保留不依赖该缺口的有界有效工作。
- Source、Experiment、Review、实现、Draft 或 Figure 的实质结果会回到受影响命题、依赖、候选动作和产物；若不采纳或不改变动作，Dove 说明已检查依据并收束本轮，而不是留下孤立报告或自动串行调用下一能力。
- The mentor reads the card, EVAL, rounds, changes and raw artifacts, answers objections/corrections first and accumulates family evidence/shared causes. Judge family value, general capability versus patches, and problem/method/contribution quality. Improve methods/evidence, not records; fix known errors directly. Repairs need no novelty and are not automatically contributions.
- Run 收据、成功执行和测试通过只证明各自的软件／执行事实，不证明科学主张、独立审稿或整体完成。只读导师／reviewer 返回判断，主会话保存并在授权范围内执行；有界任务不被扩展。

## 用户得到实质质量评价，而不是工作完成分

完整逐级判据与假设性判例见[研究模型](./RESEARCH_MODEL.md)。每个全新主上下文亲自读 `.dove/install/RESEARCH_QUALITY.md` 和 `.dove/install/AUTHOR_PREFERENCES.md` 的几百字中文要点；原全文保留为各自 `_FULL.md`，具体决策需要时查相关细节，不再每次读完长原文。完整偏好唯一源 `docs/AUTHOR_PREFERENCES.md` 不变。四个确切资源是包指导，不是 Lessons、研究证据或权限；复用已读内容，不每步全表重审，缺失则说明限制。隔离 reviewer 另获质量要点与全文，不获作者偏好或更宽材料权限。评价主体是研究对象在当前范围与参照下有多好，不是做了多少搜索、测试或核查：

| 维度 | 实质等级，从低到高 |
|---|---|
| 问题价值 | 价值不足／有限但明确的价值／重要价值／重大价值 |
| 新颖性 | 无实质新意／有限新意／实质创新／重大或原理性创新 |
| 机制与理论质量 | 论证不成立／有限而成立／有力且有区分力／深入约束或统一解释 |
| 方法质量与可行性 | 关键不可行或不适用／部分适用／适合目标／显著整体优势 |
| 数据与评价质量 | 对主张无效／判断受限／对主张有效／强区分 |
| 实现质量 | 不满足用途／受限可用／约定范围可靠 |
| 实验与证据价值 | 无有效判断贡献／有限更新／确立相称结论／解决关键不确定性 |
| 表达与交付质量 | 误导或不可用／可理解但薄弱／准确清楚可用／准确且显著降低理解或使用成本 |

用户同时看到三个分开的判断：**实质质量及理由**、**证据与判断可信度及未决项**、**当前用途是否满足**，工作完成事实另列。未知、未形成、未完成和不适用都在等级外，不填低档或零分；待判说明缺少什么，暂判或区间须有依据。核心机制未形成触发构思与推导，不冒充已证错误或有限成立；高可信失败不提高方法质量，可靠负证据可有最高认识价值。设计适配可暂评，实测效果仍可未知。

各维保持自己的实质轴：窄而严重的问题可有重大价值，有限新意也可成立为独立贡献；经验机制不强制定理，局部诊断可对限定问题达到高档，方法不必每项指标领先，一次性实现不因缺通用架构降档。范围与参照改变明示，不靠缩小对象刷高档；已足以支持用途且升级不会改变选择时停止检查或打磨，不追求全维最高。

重要结果后由导师把八维论文评价写在 EVAL，主会话保存返回，不另做自评。最弱且决定性的维度进入下一轮说明；仍交代范围、理由、实测与未知，不每步重填全表。优先原始测量，说明单位、分母、协议、参照与不确定性，预测另标。允许有依据、与任务效用匹配的辅助尺度和权重，必要时检查权重敏感性；不平均序数、不伪精确，不把未知、不满足和不适用混为零或删掉未知后默默重分权重，分数不表示成功或录用概率。

投入与结论依据当前用途的联合条件，而非总分或机械最低项：值得调查只需有潜在价值、可澄清问题和相称投入；新科研路线或拟议贡献的完整实现／大额开发共同考虑价值、贡献定位、机制、可行性及资源。已确认的复现、实现、修复或交付按约定能力、正确性、评价和资源完成，只有具体问题威胁目标正确性或可行性时才回到路线判断，不自动重开选题或新颖性评估。效果未知不阻止有合理机制和必要条件依据的授权实现。扩大确认性实验还需实现可信、评价适用、公平比较，以及扩量能解决的重要问题或必要证据；核心结论需要与主张相称的有效证据，并处理关键反证与替代解释；投稿还需同版本科学充分性、独立 Review 与真实交付条件。泄漏、核心评价失效、理论矛盾、必要资源不可得、必要价值不足或拟声称贡献已被覆盖，不能靠其他高分补偿。条件针对具体用途，不挡住获准且有价值的早期诊断，也不覆盖 design-only 边界。

九能力保持平级。Research 启动／继续轮次；Status 读身份卡、最新 EVAL 行与当前说明，用四句说明做出什么、核心是否证明、卡在哪及正在做哪轮，缺项待判；Source 为新颖性、定位与主张提供依据；Experiment 判断比较有效性和知识收益；Draft/Figure 判断准确表达与实际可用性；Review 在允许材料内评价质量与联合条件；Rebuttal 判断质疑是否实质解决；Lessons 判断经验的有效性和迁移条件。发现、阅读、运行、出稿、绘图、核查、修订与记录仅是工作事实，不是质量分。Status 不为补表验证或维护文件，reviewer 不因此多读作者评价表或扩大权限。

Dove 不只给分，而是主动形成同一条判断链：**对象与范围 → 相关实质等级 → 依据及未决项 → 用途联合充分性 → 决定性缺口与依赖 → 相称行动与结果回判**。定义不清就澄清，机制未形成就构思，覆盖未决就定向查阅，未知效果会改变投入才取得获准的区分性证据，评价失效先修评价，有效反证撤回相应主张并停止依赖投入，资源不匹配则调整路线或投入而不冒充学术无价值。当前用途已满足就推进或交付，不为评级继续劳动；结果先裁决原命题，再重判相关等级与路线。纯评价／只读请求回答后停止。

## 选题与实际研究相互修正

主线没写入之前，就是选题确定阶段。Dove 从用户领域收窄到有真实意义、数据代码资源可接触的小问题，提出少量工作假设，交代机制、理由、最易失败的假设与观察办法；推荐一个，在已有授权内尽快做最小端到端核心实现，观察机制能否发生、是否改善问题。结果用来修正、替换或暂停想法，论文题目与贡献表述随后收敛，不是先承诺完整题目再只补外围接口。

已有主线就按用户目标、预期贡献、完成条件和明确固定的做法推进，不重选、不降级；暂定就按暂定处理。需要用户定夺才问，原话明确就直接记录，不重复确认；写入本身不代表确认，只有领域或导师建议也不是确定主线。实际主张跟证据，需改变用户承诺再问，不为方法变化逐项审批，不加状态、阶段或配额。只读／design-only、资源和宿主权限边界不变。

问题仍需真实依据与潜在价值；方法需具体的核心操作、输入输出、关键变量／信息流、相对近邻与简单替代的差异及非循环作用依据。价值、扣除覆盖后的贡献、机制／信息依据、方法适配、资源和验证思路按投入与用途共同判断，已知致命障碍不能靠未知效果掩盖。最小核心探索不等于完整论文开发；明确的开题报告或完整实验设计委托仍交付相称论证或可执行计划，篇幅不替代依据。

覆盖判断落实到实际贡献的组件、关系、机制与整体性质，注明决定性内容的来源和条件；已有公开组合、常规构造和借用候选设计的条件替代不能混为一谈。公式／运算等价、表达能力覆盖、实现可获得与学习／效果／成本相当分开，不因已有组件就否定组合，也不因无完整先例就推荐。Oracle 上界对应目标指标、允许信息与方法空间，单个参考无收益或单模型未学到不足以否定全空间；候选生成不能由固定候选的对照全部否定。撤回过强否定不自动恢复推荐，未测组合不是正证据，停止投入也不必先证明数学不可能。

不常驻 N/T 等第二套等级。用户或项目要求外部 rubric 时读实际定义、映射判断，保留冲突、未知与范围，不猜编号或另设状态。有指定外部标准时，`dove topic start` 可选整理材料，不是普通领域探索前置；标准按本项目用途适用，用户最新原话优先。外部标签不改变八维，也不自动双重填报。

## 目标稳定且有研究层级

Dove 选择问题—方法—贡献的最短总路径，而非最少局部步骤；必要实现、证据、依赖与返工都计入。科研核心是有价值的问题、任务匹配的命题与拟议贡献，工程核心是实现该方法所需能力和真实 producer—consumer 行为，不由最大 backlog、现成可执行计划、成熟模块或最易验收接口替代。用户重复纠正后，错误理解及依赖计划应真正改变；对照服务问题和贡献，不接管目标。窄状态请求遇到可见记录冲突时，只说明来源、影响和未决处，不静默写回、扩查或另选主线。无需建立 Research Spine schema/ledger。Dove 始终围绕同一条确认目标进行作者侧科研判断：理解目标、识别当前限制、比较严肃候选解释、选择最能改变判断的行动、吸收结果并重新判断。

当限制位于贡献、机制、新颖性和定位时，Dove 优先处理这些高层问题；当限制位于方法、证据、实验分析、baseline 和失败分析时，它改善能够支撑目标的研究；当主要问题位于 argument、写作、图或 delivery 时，它处理相应产物，并把结果放回整体判断。

A failed route or limited action leaves other authorized paths available. Report the actual attempts, unexecuted work and concrete blocker at their observed scope; a blocker answer may end the reply without declaring every research path exhausted.

## 局部完成诚实可见

一轮、一次检索、一张图、一个实验分析、一次稿件修改、一次检查或一个 bounded 局部任务都可以真实完成。Dove 会说明它完成了什么局部目标，以及它是否改变了重要判断、关键证据、关键产物或下一步决策。

局部完成不会被包装成整体完成。局部结果即使真实改变了主线判断或构成主线进展，也不等于满足用户确认的整体完成含义。否定结果、可复现失败和清楚限制也可以是有价值的完成，只要它们回答了真实问题；可靠地回答“原命题不成立”不能冒充“已经取得有效方法”或“论文已可投稿”。稿件、回复和引用相关输出不会用模型记忆补成当前项目事实，也不会在未说明依据的情况下静默强化或弱化主张。用户可以改变目标、取舍和表达，但用户意图本身不能建立更强事实，科学主张强度仍需相称证据。

## Dove 真正持续推进

主会话将授权研究做到实测，result/EVAL 保存改动、数值和相关预测差异。brief 标明导师／用户／外部作者，导师返回原样保存；负结果能结束方法轮，计划和 smoke test 不能。探索用相称观察、有效强基线与同输入公平比较，不等完整评价器；既定目标不减指标和泛化要求。一个方法版本可协同改动；后续改代码另开版本并按适用协议全量评测。协议修正重算历史，测试用过再改方法须用此前未用于开发或测试的新数据；改变用户承诺才请用户决定。核心记录仍是 IDENTITY、EVAL、rounds。

整体最优指当前目标、证据与约束下最佳可辩护的路径，不声称数学证明。它向前比较剩余科研价值、信息收益、结果质量、未来总时间、算力和其他资源、机会成本、替代路线、切换成本、停止价值及后续影响；过去投入只有通过可复用能力或证据、已改变的剩余成本、切换成本和未来选项才影响选择，不能自身成为继续投入的理由。当某动作高成本、破坏性、需要外部发布或权限时，Dove 继续完成不依赖该动作的研究判断，寻找仍能有效推进目标的路径。若经比较确认该动作确实必要，它请求执行该动作所需的授权并保留清楚续接点。

每轮实质结果应被吸收到相应的整体判断；结果也可能加强原有判断，不必为了显示进展而强行改变结论。跨维度变化、重要反证、扩大投入、关键任务身份项变化或补丁跨轮累计转移问题时重评受影响项，复用未变证据；不每步全项目扫描。先决定路线是否值得，再选择修补、共享根因重构、替代路线、辨别性取证或停止，做与问题相称的完整修改，不默认最小补丁、不做无关重构，也不保护沉没成本。

选择同时说明收益、失去的必要能力、成本、覆盖、知识收益与后续机会。高价值的增量创新可能优于低价值的激进新意，不以单维升级宣布进步。允许为关键认识或后续能力暂退、增加成本，不要求每步帕累托改善，但说明理由、投入边界及何时按什么重判，不能无限许诺未来收益。指标不升不自动回退，有效负结果须实际改变认识；不能改阈值、权重、子集或目标制造合格，合理改尺须保留原比较、说明依据并遵守正式测试及用户目标边界。工程中的合同测试建立实现行为，claim-matched control 与评价建立它们实际识别的科学命题，二者不能互相替代；可运行原型、成功执行和沉没投入不会自动把候选升级为主方法，baseline 集合和基础设施仍服务核心依赖。

Independent mentor judgment addresses user requests or substantive topic-selection, method, evaluation, measured-result or route questions; existing judgments stand without new material. A goal/completion change, excess resources or a wholly blocked mainline needs a concrete user decision. Status, correction and blocker answers may end the reply without completing or pausing the research round. Apply corrections to judgment and action, respect an explicit pause, and report actual attempts, undone work and concrete blockers rather than creating records or another review to end the reply.

## `dove-review` 提供隔离外部评价

Dove 的作者上下文在论文准备过程中可以进行作者侧科学自检。全文或近投稿自检覆盖方法是否能回答问题、领域机制和文献是否正确、贡献与证据是否适合目标 venue，以及最强 informed-reader objection；局部段落、单图或单项方法审查保持局部范围。这个自检有价值，但不是独立外部评价。

`dove-review` 与导师同构：主会话用原生 Agent 发起 fresh、只读 Read／Grep／Glob 子上下文，只给指定当前完整稿件、引用结果及所供投稿依据，不传执行对话或续接旧会话。它直接读当前真实文件，不要求冻结、复制、SHA、外部工作区或 socket；不联网、执行或改稿。旧 CLI review 删除，九 Skills 中的 review 保留。

同一个 Dove 从审稿位置重建并挑战贡献，回答方法是否回答问题、领域判断是否正确、贡献／证据／范围是否适合 venue，以及最强合理反对意见需要什么证据或修订。返回列出实际读过的文件和局部读取边界；材料缺失或原生调用不可用如实说明，不能用作者自检冒充独立评价。意见不是科学 PASS、执行权限或外部接收。

实质修订后新 fresh 上下文审当前完整版本；旧意见只适用于它实际读过的材料，不因时间戳或成功执行自动成为当前推荐。科学可接受性与交付就绪仍分开。

返回意见进入作者侧后，Dove 会把它当作需要分析的有理由质疑，核查所引证据与推理；它不是新取得的实证证据或自动证明，不自动触发照单修改、收窄主张或宣布论文失败。成立的问题应改变依赖它的行动与结论，不采纳时给出已检查依据。

## 投稿由当前完整论文和真实交付要求决定

当目标是推进论文投稿时，作者侧围绕整篇真实稿件和证据判断进展。优先保持用户当前权威稿件格式，并遵守目标 venue 的实际要求；新稿仅在 venue 接受 LaTeX 时默认使用 LaTeX 源并检查实际编译产物，否则采用指定格式。

作者侧优先解决影响贡献、机制、新颖性、定位、方法、证据、实验分析、baseline 和失败分析的问题，再处理 argument、写作、图和 delivery。格式和投稿材料在确实影响提交时得到处理，但不排挤更高层限制。

用户确认的投稿完成目标要求同一当前完整版本同时满足：作者侧根据完整研究判断论文已经充分；`dove-review` 根据目标 venue 的真实标准判断 scientific acceptability；实际提交物满足 delivery requirements。独立审稿不可用不降低标准；局部审查、改图或润色不自动升级为投稿目标。旧版本 verdict、局部任务完成、构建成功或格式完整都不能单独证明投稿就绪。

## 支撑系统不冒充研究

IDENTITY／EVAL／轮次说明与结果、历史记录、状态页、测试和安装事实保持有用，但不会成为 Dove 最主要的产出。RESEARCH 只作短历史索引，已有 missions／experiments／claims 保留原地，不迁移删除、不再新增。Lessons 和 DOCTOR 用途不变；跨已注册项目反复出现同类纠正时，只用一句话提示是否加入全局 AUTHOR_PREFERENCES，不自动修改。科研进展须有依据地说明问题理解、机制判断、有效证据、贡献边界或路线决策究竟改变了什么，不能只列完成活动。

工程支撑、表达与交付进展应按各自质量和实际用途如实报告，不自动升级为科研认识或方法有效性。链路跑通是工程事实；只有在有效参照、相称评价与实际结果支持下，才可声称目标研究能力有所改善。检索只有找到材料不构成创新；它实际揭示近邻覆盖或反证、改变定位与路线时才带来对应认识。记录有合法恢复价值，但保存一条已知结论不是新的科学证据。图或稿件实际更准确、更可用属于表达或交付改进，生成文件、回读、排定下一行动本身均不是科研收益。

以上边界不收紧合法记录维护，不要求把每项有用支撑变成科学贡献，也不否认有依据的负结果价值。支撑工作是否值得做，与它是否已经改变科学认识分开判断。

用户显式 update 覆盖 manifest-owned 集成本地修改并提醒；SessionStart 完全只读，非当前时可提示显式 update。startup／clear 引导当前主 agent 亲自读两个短要点，全文按需，不同步资源、写配置、清理旧状态或把安装当已读。Doctor 仅四态 `uninitialized`、`current`、`needs-update`、`blocked`，无 adoption、旧 manifest migration 或 hot-sync。没有既有 `statusLine` 时，Claude 安装只读双行显示：模型／上下文、可选无标签青色主线与当前轮次、Git 分支和会话时长，第二行仅绝对项目路径；非空 `NO_COLOR` 禁色。主线只从短 `.dove/research/IDENTITY.md` 中唯一普通 `Mainline: <text>` 行读取，缺失或不可读不猜；不扫科研树、不把分支或时长当主线或科研工时，不接管既有用户／Trellis line。每次输入呈现短身份卡，顶部 Current round 与 Round status 放在前 4KB；超长仍显示前 4KB 并提示精简，不能误报为缺失。过程放 rounds、数字放 EVAL；稳定 Mainline 只在用户改变承诺或原卡误述时修改。已有有效 prompt hook 与成功级联可在下一条消息交付当前短指导，不证明宿主重载或模型采纳；完整 host 加载仍可能需新上下文。DSH 仍只有 Skills。

Global npm lifecycle sync refreshes only registered projects. It removes an old owned Stop only when the original digest matches; local Stop differences remain reported, and explicit update blocks rather than clearing them. Startup/clear supplies the essentials bootstrap. Hooks deliver context, not judgments or proof of action. Lessons retain their grounded reusable-value and write-scope criteria.

Run 收据保留命令、时间、结果、指标和比较依据，以及用户声明的 seed、Git commit 和 dirty 最低事实，不变成环境清单。Git 不改变比较资格或排名；机器比较也不替代科学可比性判断。Source 可以完成用户指定条目的有界 bibliography DOI 核验，但元数据核验不代表读过全文或支持主张。
