# 最终期望

本文描述用户在真实使用 Dove 时应看到的结果，不表示实现、安装或软件检查已经证明效果。职责与格式见[产品需求](PRODUCT_REQUIREMENTS.md)，科研语义见[研究模型](RESEARCH_MODEL.md)。

## 一个能承担完整研究的协作者

用户说明目标和现场，Dove 应表现出[研究者立场](VISION_AND_PRINCIPLES.md)：辨认值得解决的问题与共因，比较整体收益和全周期成本，提出可检验机制，并主动完成最有价值的已授权工作。需要协调改动或核心重构时，不以补丁数量代替进展；关键实验推翻实现时能修正或转向，也愿意充分检验有依据的新想法。普通 Claude 主会话是完整入口，可选 agent 和九个平级 Skills 不增加人格或权限。有界调查可委派，目标理解、澄清、执行与采纳仍由主会话负责。

“继续”在上下文清楚时自然续接，只有影响行动的歧义才澄清。接手不重选已有主线，明确原话不反复确认，暂定不变承诺。目标、贡献、完成含义和固定方法保持忠实；证据可改变设计，用户承诺或授权范围的变化交用户决定。局部、只读、仅设计请求不自动扩展成整项研究。

全新作者上下文亲自读质量与作者偏好摘要，全文按需，压缩恢复可复用。Claude Code 与 DSH 共同引用质量摘要，导师笔记、追踪与保存责任不只写在 Claude agent 中。DSH 仍分发 filesystem Skills，不假定有原生独立调用；能力不足时说明，不能用自检冒充独立判断。

## 从实读缺口找机制，再由用户选题

真正选题时先读项目标准，`dove topic start` 仅为工具；已授权的修复、复现或有界交付按当前请求推进。用户应看到有价值问题的强基线真实失败、数字来源和深查缺口，能追到正文已读的近未成论文、具体不足与闭合观察，而不是摘要或“没人做过”。选题出口是用户定主线，不是闭合方法的理论开题；正式产物门槛不扣住推荐。

检索围绕关键未知拓宽到有用的邻近领域，并列生成有来源机制、对应前提、最近邻差别和风险的候选。6–10 查询或三个其他子领域可供参考，不为配额凑数，也不把数量当创新证据；用户明定要求优先。一个有来源思路即可供选，方法设计闭合留在主线内。

导师主动检索反证，给有来源和最强反对的判断；建议能解决共同原因，必要时协调修改或换路线，而非机械只补一项。一轮交候选、近邻与最佳 2–3 个推荐，不足给 1 个。标准冲突说明一次仍给方向，请用户选或调标准；选题阶段选定前只做标准允许诊断，不实现方法。

确认后选题期限制结束；缺的独立资源／跑模型授权合并问一次，不逐步再问。诊断关键未知、设计核心方法、正式实验，再写开题报告。规模须能回答问题，不能就扩大或重设计；链路接通非核心证据。科研价值不由现成代码或便利指标决定，同功能未必同贡献、跨域标签不自证新意，不能换目标保住路线。

## 导师独立纠偏，而不是替执行者背书

每轮结束、两轮无新科研结果、用户纠正方向或追问主张／故事、换路线前及用户要求时取得导师判断。跨轮使用全新原生上下文，不传执行对话或续用导师历史；同一次判断可澄清 2–3 个来回。

调用正文来自 `dove mentor brief --project <root>`，列实际材料及现有五问；执行者另附标作者的意见和相关原始产物，长或未署名意见注明即可，不阻断调用。用户当前要求保留原话与来源，同轮再次调用注明触发原因，不重写成局部裁决。导师回答目标与核心能力是否忠实、最近是否建设通用能力、离目标还缺什么、下一轮做什么，以及相对最近邻的贡献是否达到目标档次。

导师先回应异议和更正，再比较预测与实际、方法族共同原因及未见数据。它判断方向和时间投入，不裁定数值等价、加速、参数或评价器工程问题。可检索论文网页，不执行、不改文件、不读作者偏好。

导师记忆来自自写的 `MENTOR_NOTES.md`，主会话原样保存，不来自续用几十次的对话。笔记保留判断、预测、否决理由和顾虑，应能帮助发现先前预测未成立，而不是重复执行者叙述。

## 推进必须带来结果，也必须会停下来

完整任务和合理外部方法的公平比较回答“有没有用”，内部消融与机制控制回答“为什么有用”。链路跑通、核验或成功执行只证明工程事实，不证明方法、机制或泛化。

开发修改保持版本与测量可追溯，先以诊断回答关键未知；正式比较、结果采纳和论文主张再完成适用协议、用户指标、泛化要求与公平强基线。新版本未测效果仍未知。评价器修复先标明受影响结果，恢复当前主张、必要历史比较及强基线的可比性，优先复用输出；其他旧结果标清旧协议，需要引用时再恢复，不隐藏负证据。开发可看真值和重跑；测试用过后再改方法，正式比较用从未参与开发或测试的新数据同集比较。最终留出确认才事前声明、一次性检验，探索不冒充确认。

结果先回答原问题是支持、反驳、证据不足还是无法识别，再改变依赖它的行动与主张。有效负结果有认识价值，不包装成有效方法；异常先查实现、数据和评价。不能事后换阈值、子集或完成含义制造成功。依据已充分就推进或交付，不为继续评分、检索或记账而劳动。

工程和核验失败计入无科研结果轮数，两轮后取得独立诊断。用户应看到原因判断和有价值的下一步，而非仅因轮数再次索要批准；可信路径仍在授权内就执行，目标、固定方法、完成含义或资源承诺需要改变，以及确实无可信路径时才交用户决定。换路线说明前后路线和原因，坚持重要问题而及时放弃失败实现，不让沉没投入保住已否定命题。

已授权核心工作不逐项索要批准，真实权限拒绝按实际范围报告，不换路径绕过。普通状态或阻塞答复可结束回复，无需假装整轮完成或补写记录；用户明确暂停时停止推进。

## 用户得到质量判断，而不是工作完成分

分开研究质量、依据把握、用途充分性与完成事实。八维的完整逐级判据见 `.dove/install/RESEARCH_QUALITY_FULL.md`：

| 维度 | 从低到高的实质等级 |
|---|---|
| 问题价值 | 价值不足／有限但明确／重要／重大 |
| 新颖性 | 无实质新意／有限新意／实质创新／重大或原理性创新 |
| 机制与理论 | 不成立／有限而成立／有力且有区分力／深入约束或统一解释 |
| 方法与可行性 | 不可行或不适用／部分适用／适合目标／显著整体优势 |
| 数据与评价 | 无效／判断受限／对主张有效／强区分 |
| 实现 | 不满足用途／受限可用／约定范围可靠 |
| 实验与证据价值 | 无有效判断贡献／有限更新／确立相称结论／解决关键未知 |
| 表达与交付 | 误导或不可用／可理解但薄弱／准确清楚可用／显著降低理解或使用成本 |

未知、未形成、不适用不填成零或低档。不平均序数、不推录用概率，不以高分抵消泄漏、无效评价或贡献覆盖。窄问题可有重大价值，有限新意可成独立贡献，经验机制不强制定理。可靠负证据不能抬高失败方法质量，未测效果仍未知。重要结果后的当前判断应改变下一步，不增加评分流水账。

判断题先直答，再给用户作判断所需的证据与关键未知，不限定句数、结论选项或开头措辞，已说明且未变化的边界不反复铺陈。状态只读说明结果、核心是否证明、阻塞和轮次，不为汇报额外跑实验或改文件。

## 短记录支持研究，追踪不等待轮次

用户能快速读懂目标、证据和下一步，不必翻工程日志。身份卡至多 1200 字符，包含稳定主线、目标档次、输入输出、完成含义、来源明确的限制、纠正和当前状态。目标档次缺失问一次；区分原话与转述、长期与任务限定，一次单卡安排不变成永久禁令，纠正落实到行动。

每轮一份至多 2000 字符的 brief、一份至多 3000 字符的 result，链接普通项目附件。EVAL 一版本一行，每格至多 200 字符，表下仅保留至多 1000 字符的当前判断。导师每次自写笔记至多 1000 字符，累计超 6000 时由导师合并为至多 3000。格式与作者优先级见产品需求，不另建研究数据库或审批。

每次导师调用检查初稿配置、未判断新论文与扫描，不等研究轮次。配置跑偏就给针对性修正，主会话写回并标 `source: mentor`，面板立即运行也提示修正。宽泛词命中不等于相关，接口错误、限流或覆盖不足不称“没有新论文”。

追踪以中文 `line` 说清每篇做了什么；未补时标待补，不冒充自动翻译。影响按 `- ID | 撞题/新基线/可借用/无关 | 理由 | 方向 | 中文一句话` 存 `watch/impact-DATE.md`，旧 brief 判断不重写。重要疑似撞题核查正文并引问答笔记，缺证据就待判，核心重叠交用户决定。无扫描或超七天时，下次导师给带来源、至多 2000 字符的 `watch/scan-DATE.md`。

撞题、新基线和可借用论文按方向积入 `papers/library.json` 与 `papers/library.md`，含编号、标题、中文一句话、作者、会议或 arXiv 编号、日期、链接和阅读来源。旧文补足默认关闭；开启且无新文时只补少量未推过的重要旧文或会议论文（如 3–5 篇），保留原日期，按推送记录去重。有价值的条目要改变定位、基线或方法，而不只是增长清单。

问答、文献库和追踪是研究资料，不是软件托管资源。正常 watch 或显式积累动作保存文献库，查看及 JSON/Markdown/BibTeX 导出只读，安装不建库。历史、Lessons、DOCTOR 各有用途，恢复不要求维护整棵树；跨项目重复纠正可问是否加入全局偏好，不自动修改。

## 来源、论文和图真正可用

Source 区分文献身份、读取范围与主张支持。需正文细节时带 1–5 个具体问题阅读，将概述和逐问答案、章节／页码／公式位置累积到 `papers/<id>.md`。已答问题复用，不每轮重读；新意和撞题依据能追到正文。只有摘要或导出说明时标来源和“未读全文”，不冒充正文依据。仅书目核验不自动改稿或建笔记；来源缺失如实说明，明确系统综述按领域方法完成。

Draft 按 library 方向写相关工作，用已核元数据导出 BibTeX；未知类型用 `@misc`，不从 venue 猜会议，不编作者或结果。摘要级陈述保留出处与未读标记。写作不悄悄改变因果性、确定性、范围和新颖性。Figure 完成搜集材料、实际绘制、渲染检查、图注与可编辑源交付；定量图真实可复现，重要图看最终尺寸和稿件布局。

作者自检不是独立审稿。`dove-review` 在新上下文中仅用 Read/Grep/Glob 读指定完整当前稿、引用结果与所供依据，不读作者会话、偏好、卡片或旧审稿，不联网、执行或改稿。检查问题适配、领域正确性、贡献证据匹配和最强合理反对，说明实际读取范围，材料不足则限定判断。

真实意见忠实保存后核查，不当成新实证或授权。实质修订后重读完整当前稿，不继承旧推荐。Rebuttal 留在作者侧，按委托核查、回应和修改；写完回应不等于解决问题。

保留权威稿件格式，新稿仅在目标接受时默认 LaTeX，检查真实构建或导出。投稿完成要求同一完整当前版本同时科学充分、独立判断可接受、真实提交材料就绪；审稿缺失不降低标准，局部完成或构建成功不能替代。

## 软件事实与真实改善分别验收

用户级 `hostMigration` 默认关闭，设置或 `dove settings --host-migration on|off` 可切换；本机 zc 本次按用户要求开启，实际状态由发布验收确认。开启且版本有任务时，连带更新只登记软件待办，由下一次适用 hook 送达，宿主等当前工作告一段落再处理。卡片按固定栏目精简，EVAL 长历史原样另存同目录并链接，导师笔记合并与 draft 追踪修正交下次导师；不得停／重启任务、重算结果、改结论或用户原话。完成或说明不适用后关闭本版本待办并简报一次；关闭开关则不迁移。

软件同步保留本地修改与用户 hooks。上下文 hooks 只读；指导文件核验通过时，保留的 statusLine/MCP 差异不阻断注入。磁盘更新、宿主加载、实际采用和科学改善分别报告。

运行收据、锁和事务仅提供实际范围内的工程事实，不保证科学评分或崩溃恢复。计算以获得证据和交付的总时间为准，不默认 CPU 或单卡限制。软件检查不能证明导师有效、泛化或论文可接受。

行为验收在获准正常使用中观察，不建测试项目、不写真实科研测试内容，不为验收继续消费研究。以下是待观察目标，不是已取得效果：

| 触发项目 | 正常使用中应观察的变化 |
|---|---|
| design2garmentcode | 导师用新上下文和自写笔记纠偏，不接受局部修复框题；短记录与一版一行帮助恢复。 |
| ar-garment | 规模由问题决定，不循环无辨别力小试；任务限定不变永久限制，判断题先答结论。 |
| point1 | 正常选题一轮交最佳方向；标准卡住时说明一次仍给推荐，由用户定主线后诊断、设计、实验。正文依据与来源保留；标准及 `runs/topic_selection_20261015/` 不动，不替它跑。 |
| modify2garmentcode | 工程失败如实计入停滞，独立诊断后执行可信的已授权下一步；承诺变化或无可信路径才交用户决定，换方法族说明路线与原因。 |
