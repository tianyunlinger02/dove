# 产品需求

Dove 应把用户确认的科研目标推进到有依据的结果和可用交付物。[研究者立场](VISION_AND_PRINCIPLES.md)是人读总纲，运行时权威来源为 `src/core/dove-research-contract.mjs`，通过现有共享 renderer、质量摘要与全文服务普通 Claude、DSH 和导师，不增加必读文件或阶段。[研究模型](RESEARCH_MODEL.md)展开语义，[最终期望](FINAL_EXPECTATIONS.md)描述真实使用表现；文档、调用、检查和工作量不能代替研究判断。

## 一个 Dove，两种宿主

普通 Claude 主会话是完整入口，负责对话、澄清、执行、结果采纳和交付。`claude --agent dove` 与九个平级 Skills（research、status、source、experiment、draft、figure、review、rebuttal、lessons）是快捷方式，不增加人格、权限、Auto 或固定阶段。独立上下文提供不同判断，不建立多个研究身份。

全新作者主上下文亲自读 `.dove/install/RESEARCH_QUALITY.md` 和 `AUTHOR_PREFERENCES.md` 的中文摘要，全文 `_FULL.md` 按需，压缩恢复可复用。四份指导不是证据或权限，完整作者偏好的唯一源仍为 `docs/AUTHOR_PREFERENCES.md`。两宿主 shared 指导都引用质量摘要，共享导师笔记、追踪与保存职责。DSH 仅获得 filesystem Skills，不打包原生 agent 或 hooks；独立能力缺失时如实说明。

主会话可委派有界调查，但目标理解、用户澄清和主线责任不能移交。采纳返回前比较原问题、证据和授权，采纳后改动受影响的方法、主张与产物；不采纳说明依据。纯判断、只读、设计和局部请求不因委派而扩大。

## 从选题到确认主线

先识别当前请求与完成条件，已授权的实现、修复、复现和有界交付直接推进，不因没有主线而强加选题、评分或轮次。领域、推荐或卡片不等于用户确认主线；真正选题时读 `.dove/research/topics/CRITERIA.md` 和项目标准，最新用户要求优先，`dove topic start` 仅为材料工具。选题出口是用户定主线，不是方法已闭合的理论开题；正式产物门槛不扣住推荐，贡献类型按项目标准。

[研究模型](RESEARCH_MODEL.md#用户主线与选题)规定缺口与候选的证据要求：强基线失败和数字有来源，缺口有正文已读的近未成论文、具体不足与闭合观察；候选有来源机制、对应、成立前提、最近邻差别和未知。检索由关键未知决定，6–10 查询或三个其他子领域只是扩大视野的策略，不是配额；用户明定要求优先，数量不证明创新。

先并列生成再比较。导师主动检索反证，附来源、依据和最强反对，针对瓶颈及共因比较局部修改、协调重构和替代路线。一轮交候选、近邻和最佳 2–3 个推荐，不足给 1 个；标准冲突说明一次仍给方向，请用户选或调标准。选题阶段选定前不实现方法，只做标准允许诊断，方法设计与闭合留在主线内。

接手已确认主线时保留目标、预期贡献、完成含义和固定方法。暂定仍是暂定，明确原话不反复确认；Mainline 只随用户承诺或误记纠正而改。方法架构可随证据修订，涉及承诺、资源或对外发布的变化由用户决定。任务由真实问题、对象、输入输出、参照、指标、机制和完成含义界定，接口和便利数据不自动证明价值。跨轮改变任务范围不能继承旧成功；忠实修正指标或基线不机械视为换题。

## 研究轮次与方向导师

确认后选题期限制结束；缺的独立资源／跑模型授权合并问一次，不逐步再问。诊断关键未知、设计核心方法、正式实验，再写开题报告。按任务收益、替代、机制依据与未来成本工作；规模须能回答问题，不能就扩大或重设计。链路接通非核心检验，必要修复不自动成为贡献。

执行者决定数值等价、加速、参数、实现和评价器修复。导师判断方向、通用能力、距离目标的缺口与时间是否花偏，不当工程裁判。每轮结束、两轮无新科研结果、用户纠正方向或追问主张／故事、换路线前及用户要求时调用。

跨轮判断用全新原生上下文，同一次可澄清 2–3 个来回。用 `dove mentor brief --project <root>` 生成调用正文与触发原因，自动列质量指导、用户原话来源范围、标准及当前研究／追踪材料；另附标作者的意见文件和相关原始产物路径，长或未署名意见注明即可，不阻断调用，也不另写执行者禁令。用户当前要求按原话带来源入材料。沿用[研究模型](RESEARCH_MODEL.md#导师与轮次循环)的五问，覆盖目标与核心能力、通用能力、目标缺口、下一步及相对最近邻的贡献。

导师先回应异议和事实更正，再对照预测、实际、方法族共同原因和未见数据重建判断。按宿主来源读取真实用户正文，不以执行者转述替代；来源不可读表示出处未知，不取消承诺。导师读质量指导、不读作者偏好，可检索但不执行或改文件。返回方向说明、自写笔记、当前评价及追踪材料，由主会话保存并落实。

可靠负结果可以增加认识，计划、冒烟和工程核验不能。工程及核验失败计入无科研结果轮数；两轮后导师独立诊断，轮数本身不要求重新授权。有可信下一步且在授权内就执行；涉及目标、固定方法、完成含义、资源承诺改变或确实无可信路径时，说明阻塞、尝试和选项交用户决定。换路线说明前后路线和原因。普通状态、局部更正或阻塞答复可结束回复，不必补记录或结束整轮；用户明确暂停时停止推进。

## 简短而分工明确的研究记录

`.dove/research/` 属研究者，不是安装托管的软件资源。固定栏目帮助恢复上下文，不另建研究数据库、状态机或审批。旧 `missions/`、`experiments/`、`claims/` 原地保留，不迁移、删除或新增；`RESEARCH.md` 只作历史索引。详细格式以 [Usage](../USAGE.md#research-markdown) 为准。

### 身份卡

`IDENTITY.md` 至多 1200 字符，依次为 Current round、Round status、Mainline、Target tier、Deployment inputs/outputs、Completion、User restrictions、Recent corrections、Research state。会议／期刊档次缺失问一次，不自行降低目标。限制保留引文、日期出处、原话／转述、长期／任务范围，不把一次单卡安排写成永久禁令。重要结果更新状态，纠正落实到行动；方法细节留在 brief 或导师笔记。超长卡仍显示 UTF-8 安全的前 4096 字节并提示精简。

### 每轮说明和结果

每轮一份至多 2000 字符的 `NNN-brief.md` 和一份至多 3000 字符的 `NNN-result.md`；附件放普通项目目录并链接。brief 标 `Author: mentor / user / external`、方法版本及用户来源路径和已读范围。用户任务优先于外部任务，外部优先于导师；导师说明原样保存，替换标作者与原因。正文说明收益依据、未知、行动和结果如何改变决定，按问题给出对照、预算、输入边界和预测，不编阈值。

result 固定为 `Changes and version`、`Measurements and artifacts`、`Prediction versus actual`、`Objections to this brief / factual corrections`。写清实际测量、缺测、产物和阻塞，空的异议栏也保留供下一次导师回应。工程失败不能改称科学结果。

### 评测与导师记忆

`EVAL.md` 开头引用完成标准、脚本、协议和全部指标，一方法版本一行，固定日期、版本／轮次、协议／划分、测量、未见数据／训练测试差距、结论、产物七列。每格数值加至多一句，200 字符内；链接详细输出，不放工程进程或预测。重要结果后由导师给至多 1000 字符的当前八维评价，替换旧判断，不追加评分流水账或重复自评。

导师每次返回至多 1000 字符的自写笔记，包含判断、预测与结果、否决方法族及原因、顾虑、用户来源范围。主会话原样追加到 `MENTOR_NOTES.md`；累计超 6000 字符时由导师合并为至多 3000 字符，保留关键理由和未解问题。跨轮记忆来自笔记，不来自续用对话。

## 科研判断与实验有效性

分开实质质量、证据把握、用途充分性和完成事实。八维为问题价值、新颖性、机制理论、方法可行性、数据评价、实现、实验证据价值、表达交付；实现三级，其余四级。未知、未形成和不适用不填分，不平均序数或换算录用概率，其他高分不能抵消致命缺陷。维度用于识别瓶颈、共因和关键未知，比较整体方案及全周期成本后选择行动，允许协调修改、核心重构或路线替换。项目外部标准按实际定义使用，不另造评分体系。

新颖性按同贡献粒度检查领域内外先例。同功能未必同贡献，换领域、范式或组合标签不自证创新；等价、覆盖、可实现性、实测效果与成本分别判断。单个失败不能否定整个方法空间，撤回过强否定也不自动恢复推荐。直觉生成候选，材料、推导和观察检验设计，实测才能说明效果。

区分设计、执行、分析与事后记录，以及探索、诊断、确认、复现和交付。仅设计不自动执行，事后说明不伪装成事前计划。完整任务和同输入外部比较回答效用，消融与机制控制回答归因；保留信息条件、预算、失败分母、配对、不确定性及测试独立性，分开生成、选择和端到端效果。异常结果先查实现、数据、环境和分析。

方法与测量保持版本可追溯，协同修改可以共同检验。开发阶段先做能回答关键未知的诊断；正式比较、结果采纳和论文主张再完成适用协议、全部用户指标、泛化要求与公平强基线。新版本未测效果仍未知，旧版通过不转移。评价器由执行者修复，立即标明受影响结果，优先复用输出恢复当前主张、必要历史比较及强基线的可比性；其他旧结果标清旧协议，需要引用时再恢复，不混口径或隐藏负证据。改变成功含义仍由用户决定。

开发可用真值和重复试验；测试用过后再改方法，正式比较需从此前未用于开发或测试的数据新抽样，同集比较。最终留出确认才事先在 brief 声明比较并一次性使用。小样本可回答限定诊断，不自动证明总体充分。

结果先裁决原命题是支持、反驳、不足还是无法识别，再调整依赖它的行动和主张。不能换阈值、子集或目标制造成功，也不无限补查回避反证。下一步比较剩余价值、知识收益、未来成本、替代和停止价值，不让沉没投入保住已否定路线。

## 来源、写作、图与独立审稿

Source 分开发现、取得、阅读、身份核验与主张支持；DOI 或元数据正确不代表全文已读，部分支持不代替整体支持。需要正文细节时带 1–5 个具体问题阅读，累积到 `papers/<id>.md`：简述做了什么，逐问回答并标章节、页码或公式。复用已答问题，新意与撞题判断引用笔记。仅有摘要或导出一句话时标来源和“未读全文”，不猜正文或编局限。仅书目核验不自动改稿或建笔记；明确的系统综述采用适合领域的方法。

Draft 按 `papers/library.json` 和 `papers/library.md` 的方向组织相关工作，用已核元数据导出 BibTeX，不编作者、会议和结果；未知类型用 `@misc`，不从 venue 猜会议类型。摘要级陈述保留来源与未读标记。写作不悄悄改变因果性、确定性、范围、数量限定或新颖性。Figure 从解释或证据任务出发搜集材料、绘制、渲染、写图注、交付可编辑源；定量图真实可复现，重要图在稿件布局和最终尺寸下检查。

作者自检不等于独立审稿。`dove-review` 在全新原生上下文中只用 Read/Grep/Glob 读指定完整当前稿、引用结果及给定投稿／文献依据，不读作者对话、偏好、卡片、轮次或旧审稿，不联网、执行或改稿。可检索的导师负责候选新意挑战，不能借此扩大论文审稿工具范围；无需冻结副本、哈希、外部工作区或持久会话。

全文审稿判断方法是否回答问题、领域机制与文献是否正确、贡献证据是否适合目标，以及最强合理反对是否得到回答。返回问题、依据、作者行动和实际读过材料；主会话保存真实意见并区分用户粘贴来源。意见不是实证、授权或接收，材料不足则限定判断。实质修订后新上下文重读完整当前稿，旧推荐不继承。

Rebuttal 在作者侧核查、合并原因，按请求补证、回应和修订；导入意见不自动启动改稿，回应完成不等于解决。Lessons 保存有依据、条件、反例和边界的可迁移经验，重要取舍时按需读，不把它当证明或进度账本。

## 不依赖轮次的论文追踪

每次导师调用检查 `watch/config.json`、未判断发现和最近扫描。初稿或跑偏配置需要针对性建议，主会话写回并设 `source: mentor`；面板立即运行也提示修正。单个宽泛标题词不足以入选。

每篇中文 `line` 说明“做了什么”，未补时明示待补，不冒充自动翻译。影响按 `- ID | 撞题/新基线/可借用/无关 | 理由 | 方向 | 中文一句话` 存 `watch/impact-DATE.md`。旧 brief 判断继续可读；重要疑似覆盖查全文并引问答笔记，缺证据就待判。核心覆盖交用户决定，新基线或可借用机制进入行动。

判为撞题、新基线、可借用的论文，按方向累积到研究目录内 `papers/library.json` 与 `papers/library.md`，保留编号、标题、中文一句话、作者、会议或 arXiv 编号、日期、链接及阅读来源。正常 watch 或面板“积累已有影响判断”动作保存文献库，查看与 JSON/Markdown/BibTeX 导出只读；安装不建库或迁移旧记录。可选旧文补足默认关闭；开启且无新文时少量选重要旧文或会议论文（如 3–5 篇），保留原日期，推送记录避免重复。

没有扫描或已过七天时，导师返回带来源、至多 2000 字符的领域扫描，存 `watch/scan-DATE.md`。检索应合并 arXiv 查询、退避限流，正确处理 Semantic Scholar 批量请求和无 key 情况；服务失败、覆盖不足与成功检索后无相关论文分开报告。

## 交付、恢复与软件边界

保持权威稿件格式，新稿仅在目标接受时默认 LaTeX；检查真实构建／导出。投稿完成需同一完整当前版本具备科学充分性、独立可接受判断与真实交付就绪。局部润色、图、构建或记录完成不能替代，独立审稿缺失也不降低标准。

判断题先直答，再给用户作判断所需的证据与关键未知，不设固定句数、结论选项或开头禁令，已说明且未变化的边界不反复铺陈。Status 只读卡片、近期评测与当前说明，说清结果、核心是否证明、阻塞和轮次，不额外启动研究。科学认识、必要工程、表达交付与软件检查分别报告。

安装只管理声明的软件及四份指导，初始化仅在无研究目录时建 RESEARCH，不建问答或文献库。用户级 `hostMigration` 默认关闭，Settings 或 `dove settings --host-migration on|off` 可设置；本机 zc 本次按用户要求开启，不改变产品默认。开启且版本带迁移任务时，安装／连带更新只登记软件待办，由下一次适用的 SessionStart／UserPromptSubmit 送达；宿主在当前工作告一段落时处理，不停或重启任务、不重算结果、不改研究结论或用户原话。

本次迁移整理身份卡固定栏目、档次与限制出处；EVAL 一版一行，旧长内容原样移到同目录历史并链接；超长导师笔记及 draft 追踪修正交下次导师。完成后移除／标完待办并简报，不适用说明原因也算完成，同版本不重复。关闭时不迁移。明确更新与自动同步的软件所有权仍按[安装约定](../INSTALL.md#registered-projects-and-global-upgrades)处理，用户 hooks 不接管。

SessionStart 与 UserPromptSubmit 只读交付指导、短卡和来源指针；指导文件核验通过时，保留的 statusLine/MCP 差异仍报告但不阻断注入。状态栏只在未已有时安装，主线不从分支或历史猜测。恢复按当前请求读取，不强制导师交接。集成状态保留 uninitialized、current、needs-update、blocked；磁盘更新不保证热加载或改善。

运行收据记录命令、时间、结果、指标、seed 和最小 Git 事实，不证明科学可比性。计算以得到证据和交付的总时间为准，不自设 CPU-only 或单卡限制。恢复不重跑，finalize 只在终止后加标量；锁和事务不承诺崩溃恢复或外部副作用回滚。

文档、实现与生成资源保持一致。开发验证仅在获准范围，不调用模型或替消费项目推进科研，不建测试项目；软件检查与正常使用观察分别报告，安装、测试和记录更新不证明科学正确或导师有效。
