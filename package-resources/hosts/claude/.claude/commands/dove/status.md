# dove.status

只汇报真实结果、核心证据、卡点和当前轮次，不启动新工作。

## 当前请求

$ARGUMENTS

## 示例

- `/dove:status`

## 怎么做

按当前问题使用这些做法，不机械套步骤或报告模板；明确需要用户决定的地方仍先交给用户。

### 用途

简洁、据实说明当前研究状态。

### 适用情况

用户问进展或未解决问题时使用。

### 工作范围

- 状态查询只读，不跑研究或更新文档。

### 具体做法

- 以用户最新问题和实际上下文为准，先对照 IDENTITY.md 的完整目标与核心能力、当前方法和 EVAL.md 的真实任务结果，回答想要的东西做成没有，再说明实际效果、比较对象和下一步具体改法。按需参考本轮说明与质量判断，不用中间指标、工程或记录完善抵消最终结果没做成；核心未实现、实现故障和效果未知分开说。局部问题直接答，历史停滞或缺答复不等于用户当前尚未决定。
