# dove.status

只汇报真实结果、核心证据、卡点和当前轮次，不启动新工作。

## 当前请求

$ARGUMENTS

## 示例

- `/dove:status`

## 怎么做

按当前问题使用这些做法，不机械套步骤或报告模板；明确需要用户决定的地方仍先交给用户。

### 用途

简洁、据实说明当前研究状态。

### 适用情况

用户问进展或未解决问题时使用。

### 工作范围

- 状态查询只读，不跑研究或更新文档。

### 具体做法

- 读 IDENTITY.md、EVAL.md 开头的主指标和八维走势、最近几行方法版本和本轮说明，先直接回答用户，再说做了什么、真实结果、意味着什么和离最终结果还差多少、下一步。说明核心能力是否证实、卡在哪里，以及本轮对准哪一维、哪天见分晓；数字解释含义，缺证据留未知。
