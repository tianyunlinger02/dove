# paper-factory-citation-discipline

- Never invent a citation from memory.
- Use `.paper/sources/index.json` as the canonical registry.
- Keep `.paper/bibliography/citation-log.md` synchronized with actual draft usage.
- Mark missing references as gaps instead of fabricating them.
